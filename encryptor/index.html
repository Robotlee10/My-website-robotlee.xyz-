How it works

three steps, all local
01

Key from password

Your secret key is stretched into a 256-bit key with PBKDF2 (600,000 rounds) plus a fresh random salt — so guessing it is slow and every message is unique.

02

Seal the message

The text is encrypted with AES-256-GCM, which also stamps it so any later tampering is detected on decrypt. The result is one shareable token.

03

Share & decrypt

Send the token however you like. The recipient pastes it here with the same key to unseal it. Lose the key and it's gone — there is no recovery.
